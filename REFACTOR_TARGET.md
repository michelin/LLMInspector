# LLMInspector — Target Architecture (post-refactor)

This document describes what the `llminspector` package looks like at the **end** of the
refactor. For the ordered, checkable path to get here, see [REFACTOR_PHASES.md](REFACTOR_PHASES.md).

## Why this refactor

The current package (`llm_inspector/`) is a flat module set plus a Streamlit multi-page UI,
driven by `config.ini` + `.env`, and is **mid-refactor / partly broken**:

- Live evaluation path is `EvalMetrics` (async, already code-driven) + `helper.py`'s async pipeline.
- `metric_calculation.py` (thread engine + `*Metrics` dataclasses) is **stale** — calls removed methods.
- Top-level `evaluate()` is **broken** (old signature; missing `calculate_metrics`/`export_insights`).
- `RagEval.rag_evaluation()`/`export_eval()` are **called but don't exist**; `generate_testset()` never sets `self.test_df`.
- `constants.py` is 148,799 lines; only **6 symbols** are used.
- **Azure-OpenAI-only**, hard-coded model names, **two inconsistent auth styles**.
- Silent perturbation bugs in `add_contraction` / `add_abbreviation`.

**Goal:** a DeepEval-shaped package (`test_case`, `dataset`, `metrics`, `models`, `evaluate`,
`synthesizer`), Streamlit removed, config-driven → code-driven, shipped as a wheel to
Artifactory via the existing `pydnx_packaging`.

**Design decisions in force:**
1. Package renamed `llm_inspector` → **`llminspector`**.
2. Dead/broken code is **dropped and rebuilt**, not carried forward.
3. Metrics are **class-based** (`Metric.measure(test_case)`) from the start.
4. A **provider abstraction** (`BaseLLM`/`BaseEmbeddingModel`) is introduced now, Azure first.

**"Port without changing logic" means:** the *computation* of each metric and generation
stage (prompts, ragas calls, thresholds, HF paraphraser, perturbation algorithms, arg-order
quirks) is preserved. Interfaces, orchestration, provider access, and packaging are rebuilt.

## Public API (target)

```python
from llminspector import evaluate
from llminspector.test_case import LLMTestCase
from llminspector.dataset import EvaluationDataset, Golden
from llminspector.models import AzureOpenAIModel
from llminspector.metrics import FaithfulnessMetric, AnswerCorrectnessMetric, PIIDetectionMetric
from llminspector.synthesizer import AlignmentSynthesizer, AdversarialSynthesizer, RagSynthesizer

model = AzureOpenAIModel(deployment="gpt-5-mini", api_version=..., azure_endpoint=...,
                         token_provider=...)          # or api_key=...
dataset = EvaluationDataset.from_excel("golden.xlsx", input_col="question", ...)
result = evaluate(dataset,
                  metrics=[FaithfulnessMetric(threshold=0.7, model=model),
                           AnswerCorrectnessMetric(model=model)])
result.to_excel("insights.xlsx")
```

## Config → code mapping (replaces `config.ini`)

| Old `config.ini` | New code-driven home |
| --- | --- |
| `[Insights_File]` cols/thresholds/metrics | args to `evaluate()` + per-`Metric(threshold=...)` |
| `[Alignment_File]`, `[Tag_Augmentation_Key]`, `[Augmentation_Type]` | `AlignmentSynthesizer(...)` constructor args |
| `[Adversarial_File]` capability/subcapability/samplesize | `AdversarialSynthesizer(...)` args |
| `[RAG_File]` dirs/testset_size/prompt/thresholds | `RagSynthesizer(...)` args |
| `.env` Azure creds | `AzureOpenAIModel(...)` args (optional `Settings.from_env()` convenience) |
| dead `ban_substring_values` | dropped |
